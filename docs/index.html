Trust 🔐

Why Tweeticcini asks for a Twitter/X session

Alert delivery depends on an active session

Tweeticcini needs a connected Twitter/X session so it can check the accounts your server wants to monitor and keep alert polling running.

Stored session information is encrypted

Connected session secrets are stored in encrypted form, and a server administrator can remove the session from the dashboard whenever they want.

Expired sessions fail safely

If a session expires or stops authenticating, Tweeticcini shows the session warning in the dashboard so an admin can reconnect or remove it.

FAQ ❓

Questions people usually ask before connecting a server

Why is a Twitter/X session required?

Tweeticcini uses a connected session to watch the Twitter/X accounts your server cares about. Without that session, it cannot keep those monitor checks running.

What happens if the session expires?

The dashboard will show that the session needs attention, and alerts tied to that session may stop until a server admin reconnects it or swaps to another connected session.

How do I reconnect or revoke a session?

Open the dashboard, go to Sessions, and either reconnect the existing session or remove it entirely. Removing the session revokes Tweeticcini’s use of that stored session for your server.

What Discord permissions do I need?

You need to be able to manage the server in Discord to access the dashboard for that server. The bot also needs access to the channels where you want alerts to be posted.

How do trials, cancellation, and billing work?

Paid plans include a 7-day trial when available. You can start checkout from the dashboard, and once a paid subscription is active you can use the billing portal to review or cancel it.
